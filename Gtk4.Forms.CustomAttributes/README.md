# Gtk4.Forms.CustomAttributes

Test and issue-tracking attributes for Xamarin.Forms — `[Issue]`, `[Preserve]` and related markers
used by the control gallery and test suites.

```
dotnet add package Gtk4.Forms.CustomAttributes
```

## About this fork

Maintenance fork of the `5.0.0` branch of [xamarin/Xamarin.Forms](https://github.com/pieroviano/Xamarin.Forms),
published under the `Gtk4.Forms.` package prefix. Upstream Xamarin.Forms reached end of support on
**May 1, 2024** and was succeeded by [.NET MAUI](https://github.com/dotnet/maui); new
applications should target .NET MAUI instead.
